# Junxion releases

Downloads of **Junxion** for macOS: a local context engine for AI coding agents. Switch between
Claude Code, Codex and Gemini CLI without starting over.

- Website and live demo: **https://junxionhub.dev**
- Download: the latest `.dmg` under [Releases](../../releases/latest)
- Privacy: https://junxionhub.dev/privacy

The app updates itself from this repository's releases. This repository holds only the built app,
not its source code.
